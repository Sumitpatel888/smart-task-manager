# Smart Task Manager — FS36 Mini Hackathon

A production-style React To-Do / Smart Task Manager built for the Sheryians Coding School FS36 Mini Hackathon.

## Requirements covered
- `useState`, `useEffect`, `useContext`, `useCallback`, `useRef`
- React Router with `/`, `/completed`, `/stats`, and dynamic `/task/:id`
- `localStorage` persistence
- Dedicated Axios instance in `src/api/axios.js`
- Segregated API service in `src/api/todoApi.js`
- Search and sort
- Add, edit, delete, complete/incomplete
- Responsive clean UI

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
